Package catalogue, enquiries, fixed departure dates and PayPal booking capture for iFly Nepal.

== Description ==

Companion plugin for the iFly Nepal theme. Provides:

* A `package` custom post type with a `package_type` taxonomy (Retreat, Trek, Tour, Volunteering, Workshop).
* Nested-category permalinks for packages.
* An in-house enquiry form with queryable storage, plus WhatsApp click-to-chat.
* Fixed departure dates as informational display (no availability or capacity logic).
* A Bookings admin screen populated from a PayPal webhook / IPN listener.
